# Project 2B - AI Lead Follow-up Tool

Micro-SaaS idea: AI agent that helps small service businesses (HVAC, plumbing, landscaping) automatically follow up on website leads and missed calls.

## Goal
Generate real revenue toward 200M RMB target through bootstrapped SaaS + services.

## Current Status
MVP landing page. Next: integrate AI, payments, deploy.

## Stack
- Next.js (App Router)
- Deploy on Vercel
- AI via OpenAI/Anthropic API (user to provide keys later)
- Payments via Stripe (later)
